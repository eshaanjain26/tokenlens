About TokenLens

What is TokenLens?

TokenLens is a client-facing LLM intelligence platform for comparing cost, performance and environmental impact across frontier language models. Data is sourced from peer-reviewed research and official provider sustainability reports.

Environmental Methodology

  • Power (Wh/1M tokens) — anchored to Luccioni et al. 2023 "Power Hungry Processing" (direct GPU measurement on A100s). 6B model ≈ 540–640 Wh/1M. Larger models scale as params^0.65.
  • CO₂ (g/1M tokens) — Power × provider grid carbon intensity (gCO₂/kWh). Source: Google Env Report 2023, Microsoft Sustainability 2023, AWS 2023.
  • Water (L/1M tokens) — Power × provider WUE (L/kWh). Calibrated to Li et al. 2023: ~500mL per 20-question GPT-3.5 session.
  • Reasoning models — 4–20× compute multiplier for extended chain-of-thought (o1/o3/DeepSeek R1).

Pricing Data

Live pricing fetched from OpenRouter API (public, no key required). Falls back to 30 curated hardcoded models if the API is unavailable. Prices may change without notice.

Important Disclaimer

All environmental figures are research-derived estimates. Actual energy, water and CO₂ values depend on real-time data center load, cooling method, and renewable energy mix. This platform is intended for directional decision-making, not regulatory compliance or audit reporting.

1️⃣ Token Counting

Tokens are the atomic unit of LLM billing. TokenLens uses a BPE (Byte-Pair Encoding) approximation calibrated to OpenAI's cl100k_base tokenizer. English text averages ~0.75 words per token (4 chars/token). Code is denser (~3 chars/token). Multilingual text varies.
🔗 OpenAI Tokenizer 🔗 HuggingFace Tokenizers 
// Token count approximation (BPE-calibrated)
inputTokens  = ceil(charCount / 3.8)          // ≈ cl100k_base average
outputTokens = ceil(inputTokens × 1.8)         // typical generation ratio

// Context window accumulation (quadratic growth)
contextTokens_turn_k = P + (k-1) × (P + O)   // P=prompt tokens, O=output tokens

2️⃣ Cost Calculation

Pricing is fetched live from the OpenRouter public API (no auth required). Prices are expressed in USD per million tokens. Input and output are billed separately.
🔗 OpenRouter API 🔗 OpenAI Pricing 🔗 Anthropic Pricing 
// Per-turn cost
cost = (inputTokens  / 1,000,000) × pricePerMInput
     + (outputTokens / 1,000,000) × pricePerMOutput

// Context accumulation multiplier (turns 2+)
contextBilling_k = inputTokens_k + (k-1) × (prevPrompt + prevOutput)

3️⃣ Power Consumption

Power rates (Wh per million tokens) are anchored to Luccioni et al. 2023 "Power Hungry Processing", which measured 88 NLP tasks across 10 model families on identical hardware. A 6B-parameter model consumes ~540 Wh/1M tokens. Rates scale approximately with parameter count (sub-linear due to quantisation and hardware efficiency improvements).
📄 Luccioni et al. 2023 (arXiv:2311.16863) 📄 Patterson et al. 2021 (arXiv:2104.10350) 📊 Epoch AI Model Database 
// Anchor: 6B model ≈ 540 Wh/1M tokens (Luccioni 2023, Table 3)
// Per-model rates are research-calibrated; see POWER_RATES in source

power_Wh = (inputTokens + outputTokens) / 1,000,000 × powerRate_Wh_per_M

// Example rates (Wh / 1M tokens):
  GPT-4o            ≈ 3,500  (large MoE, ~280B param-equivalent)
  Claude 3.5 Sonnet ≈ 2,800  (Anthropic Constitutional AI cluster)
  Gemini 2.0 Flash  ≈   510  (efficient distilled model)
  Llama 3.2 1B      ≈    90  (tiny, on-device class)

4️⃣ CO₂ Emissions

Carbon intensity (gCO₂ per kWh) varies by provider data center location and grid. Values are sourced from provider sustainability reports and EPA/EEA grid factors. TokenLens uses per-provider profiles so that, e.g., a Google model running on a renewable-heavy GCP grid shows lower CO₂ than the same workload on a coal-heavy Chinese grid.
🌍 Google Sustainability Report 🌍 AWS Sustainability 🌍 Anthropic (AWS US) 📊 EPA eGRID 
// Provider grid carbon intensities (gCO₂/kWh):
  Google (GCP)      ≈  90  gCO₂/kWh  (near-zero renewable contracts)
  Anthropic (AWS)   ≈ 180  gCO₂/kWh  (US-East mixed grid)
  OpenAI (Azure US) ≈ 250  gCO₂/kWh  (US average)
  xAI (Tennessee)   ≈ 280  gCO₂/kWh  (TVA mixed)
  DeepSeek (China)  ≈ 600  gCO₂/kWh  (China national grid 2023)

co2_grams = power_Wh / 1000 × provider.co2_gCO2_per_kWh

5️⃣ Water Consumption

Data center water usage is reported as Water Usage Effectiveness (WUE = litres of water per kWh of IT load). It covers both cooling tower evaporation and mechanical cooling. Li et al. 2023 "Making AI Less Thirsty" quantified that training GPT-3 required ~700,000 L of fresh water. TokenLens uses inference-scaled WUE from the same framework.
📄 Li et al. 2023 (arXiv:2304.03271) — "Making AI Less Thirsty" 🌍 Google DC Efficiency 🌍 AWS Water Stewardship 
// Provider WUE values (litres of water per kWh):
  Anthropic (AWS)   ≈  3.8 L/kWh  (AWS 2023 WUE report)
  Google (GCP)      ≈  5.4 L/kWh  (Google 2023 sustainability)
  OpenAI (Azure)    ≈ 11.5 L/kWh  (Microsoft 2022 WUE)
  DeepSeek (China)  ≈ 19.0 L/kWh  (Li 2023, estimated China DC)

water_mL = power_Wh / 1000 × provider.wue_L_per_kWh × 1000
           // × 1000 converts litres → millilitres for human-scale display

⚠️ Limitations & Caveats

All environmental figures are research-derived estimates, not audited measurements. Actual inference power consumption depends on batch size, hardware utilisation, cooling efficiency, and model quantisation — none of which are publicly disclosed by providers. TokenLens uses the best available published values as conservative anchors. Treat all CO₂, water and power figures as order-of-magnitude directional benchmarks.
